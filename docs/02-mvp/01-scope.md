# Scope P0, P1 y exclusiones

**Estado:** Normativo P0 · **Versión:** 1.0 · **Fecha:** 2026-11-26

**Objetivo técnico:** demostrar un ciclo completo y verificable de una pregunta externa relevante, sin negocio completo. Una persona puede comprender, pronosticar, ver consenso, registrar una decisión de prueba y verificar el resultado y score.

P0 obligatorio: un contrato, una pregunta LIVE condicionada a fuente validada, un escenario DEMO sintético resoluble en testnet, forecast humano y agente (si proveedor falla, fixture etiquetado NO satisface prueba de agente vivo), baseline 50% de control o climatología documentada, mediana, evidencia, resolución firmada, Brier, registro de decisión local demo, verificador público, deployment testnet y app, tests. El LLM solo emite pronóstico estructurado, no autónomo en producción. Una pregunta viva puede quedar abierta al cierre del concurso.

P1: segundo adaptador, automatización de curación, ponderación experimental, credencial portable, alertas, pago fijo USDC testnet, servidor de decisiones con auth. No construir si P0 incompleto.

No scope: marketplace, compras de picks, custodia, token, derivados/apuestas, enterprise auth, multi-tenant, microservicios, varios países, drones, modelos climáticos, oráculo descentralizado, backtesting masivo, API comercial, precios reales de clientes, datos internos sensibles. No añadir 9 agentes. Las carpetas de visión no son tickets.

Criterio de salida: evidencia de transacciones reales y pruebas, no slides ni mockups. Si fuente LIVE falla, documentar bloqueo y mantener demo técnica honesta; no fingir integración real.
